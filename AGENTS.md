# Agent Guidelines for TECH2-H26

- This file contains project-specific instructions for AI agents working in this repository.

## Python Environment

- The Python code in this repository is intended to be run with the `TECH2` conda environment, which is already present on the system.
- Run Python and Ruff through this environment, for example with `conda run -n TECH2 ruff ...`.
- Conda manages this environment: do not install any additional packages into it, and do not use `pip` to install packages.
- The targeted Python version is `3.14`.
