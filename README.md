# TECH2 H26 — AI Week

This repository is a demo for an introduction to agentic AI coding in TECH2.
We use AI coding agents to work through last year's term paper as a practice
exercise.

## Contents

### Agent configuration and skills

- [AGENTS.md](AGENTS.md): custom instructions for AI coding agents.
- Skills in [.claude/skills/](.claude/skills/) for Claude Code and
  [.agents/skills/](.agents/skills/) for other agents: reusable instructions for
  reviewing and fixing Python code style.


### Term paper and data

- [TASKS.md](TASKS.md): last year's term paper, used as the demo exercise.
- [data/](data/): survey and CPI data for the exercise.
